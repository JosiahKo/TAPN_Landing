FAQ

Does TAPN read student content?

No. TAPN only manages policy state (e.g., which apps are allowed) and timestamps. We don’t capture messages, browsing, or photos.

What phones are supported?

iOS and Android. Students install a lightweight companion app that listens for the tap-in signal and applies school policies.

What if a student doesn’t tap in?

That student's attendance will not be logged. Schools can set rules that require tap-in for attendance or network access.

Can teachers adjust rules quickly?

Yes. Teachers can manually add/remove allowed apps in the app; changes apply immediately and auto-expire with the timer.
